Link Vault

A production-ready, full-stack URL shortener and analytics platform deployed across Vercel (frontend), Render (backend), and MongoDB Atlas (database).

Features

* URL Shortening: Instant compression of long URLs into clean, shareable links.
* Custom Aliases: Tailor your short links with personalized text tags.
* QR Code Generation: Automatically generates a scannable QR code for every created link.
* Classified Analytics: Real-time tracking of click metrics and user engagement.

Tech Stack

* Frontend: React, Vite, Tailwind CSS, Axios
* Backend: Node.js, Express, Mongoose
* Database: MongoDB Atlas

Local Setup and Installation

1. Clone the repository:
git clone [https://github.com/itanmaynawani/link-vault-project.git](https://www.google.com/search?q=https://github.com/itanmaynawani/link-vault-project.git)
cd link-vault-project
2. Backend Setup: Navigate to the backend folder, install dependencies using npm install, configure your environment file with PORT and MONGO_URI, and start the server using npm run dev.
3. Frontend Setup: Navigate to the frontend folder, install dependencies using npm install, configure your VITE_API_URL environment variable, and start the client using npm run dev.
